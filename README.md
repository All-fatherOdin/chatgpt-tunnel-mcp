# chatgpt-tunnel-mcp

Локальный MCP-сервер для предоставления ChatGPT доступа к разрешённым проектам.

## Цель

Разделить работу над продуктом между удалённым проектом ChatGPT (анализ,
требования и менеджмент) и локальным проектом Codex (реализация и тестирование).
Расход лимитов и доступность подключения в обычном чате проверяются экспериментально.

## План первой версии

- Чтение файлов и просмотр структуры разрешённых проектов.
- Поиск по коду и документации.
- Ограничение доступа корневыми папками, исключение секретов и ограничение объёма ответов.
- Подключение через MCP-туннель.
- Журнал вызовов для проверки реального доступа и актуальности данных.

В дальнейшем: чтение Git diff и статуса, передача версионируемых заданий и отчётов.

## Статус

Репозиторий инициализирован. Реализация сервера ещё не начата.
