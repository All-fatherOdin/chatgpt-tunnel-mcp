# Проверка решений скиллов

Workflow 1.0.0. Ниже — сценарии для контрольного применения в отдельной сессии. При разработке выполнен анализ текстов по этим сценариям; вызовы модели с живыми мутациями не выполнялись.

| Запрос / ситуация | Ожидаемое решение | Где реализовано |
| --- | --- | --- |
| «Подготовь предложение» | Исследовать, показать draft; не create_task | planning / Подготовка |
| «Подготовь и передай» | Создать после достаточного уточнения, не спрашивать повторное согласие | planning / Передача |
| Planner доступен в Codex | Использовать нужную роль независимо от приложения | все скиллы / discovery |
| Есть worker и planner; исполнитель написал код | Не self-review | execution и review |
| Worker NOT_FOUND, planner видит Task | Проверить ID/конфиг/allowlist/store, не создать замену | execution / Получить и принять |
| SourceRef SHA устарел | Сопоставить изменения и контекст; не откатить код | execution / Получить и принять |
| Task уже reported | Прочитать отчёт, не отправлять второй | execution / состояния |
| Timeout submit после commit | Прочитать get_task/report, точный повтор с прежней expectedRevision | execution / отчёт |
| Нет исходных аргументов повтора | Остановить зависимую мутацию, не реконструировать приблизительно | все скиллы / recovery |
| Запрос вернуть changes_requested в queued | Объяснить отсутствие reopen, при поручении связанный Task | planning и review |
| Mock совпадает с кодом, но backend-контракт требовался фактический | Не принимать как доказанный; запросить достаточное evidence | review / доказательства |
| Есть сообщение исполнителя о реальном POST | Пометить как evidence исполнителя; не объявлять независимо повторённым | review / доказательства |
| Нет разрешённой среды для POST/PATCH | Не выполнять в production; blocked с limitation/question | execution / отчёт |
| Memory path пытаются записать в sourceRefs продукта | Читать другим projectId; ограничения перенести текстом | planning / источники |
| Follow-up принят | Оставить родителя changes_requested, сообщить о закрытии замечания в цепочке | review / итог |

Автоматизированные проверки в test/workflow.test.mjs проверяют исполняемые части: валидность примеров схемам, изоляцию привязок, установку/обновление и защиту локальных изменений. Они не проверяют поведение агента простым совпадением слов в Markdown.
