# Запуск туннеля двойным щелчком

В корне репозитория запустите `Start-MCP-Tunnel.exe`.

Первый запуск запрашивает runtime API key скрытым вводом. Вставьте ключ в приглашение и нажмите Enter. Следующие запуски используют сохранённый ключ. Оставляйте окно открытым, пока работаете с MCP в ChatGPT; закрытие консольного окна останавливает запущенные в нём процессы.

## Хранение настроек

- `%LOCALAPPDATA%\chatgpt-tunnel-mcp\launcher.json` — путь к tunnel-client.exe.
- `%LOCALAPPDATA%\chatgpt-tunnel-mcp\runtime-key.dpapi` — ключ, зашифрованный Windows DPAPI для текущего пользователя и устройства.
- Существующий профиль `%APPDATA%\tunnel-client\chatgpt-tunnel-probe.yaml` используется без изменения.

Ключ не хранится в Git, аргументах команд или постоянной переменной окружения. Он передаётся дочернему tunnel-client в окружении процесса. DPAPI не защищает от программ, уже выполняющихся с правами этого же пользователя. На другом устройстве ключ нужно ввести заново; файл DPAPI не является переносимой конфигурацией.

Для замены ключа из PowerShell в корне репозитория:

```powershell
.\Start-MCP-Tunnel.exe --reset-key
```

Чтобы забыть ключ, удалите только файл `runtime-key.dpapi` из указанной папки. Отзыв ключа выполняется отдельно в OpenAI Platform.

## Сборка и диагностика

EXE — небольшая оболочка над `scripts/start-tunnel.ps1`. Держите EXE в корне репозитория. Он не содержит ключей и не запускает модели через API.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-launcher.ps1
.\Start-MCP-Tunnel.exe --check
```

Используется встроенный компилятор .NET Framework Windows. Бинарник исключён из Git, исходники сохранены. EXE не подписан.

ExecutionPolicy Bypass применяется только к дочернему PowerShell, запускающему скрипт; системная политика не изменяется. Скрипт также можно запускать напрямую:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-tunnel.ps1
```

Проверка `--check` не читает ключ и не запускает туннель. Проверяются исполняемые файлы, профиль, локальная конфигурация и наличие сборки MCP. Связь с OpenAI этой проверкой не подтверждается.

Если клиент не найден, обычный запуск попросит его полный путь. При занятом порте 8080 запуск будет остановлен, чтобы не создать второй локальный daemon. Сервер автоматически не пересобирается: после изменений выполните `npm.cmd run build` и перезапустите туннель.

Лаунчер не устраняет сетевые ошибки или ответы OpenAI 403 `unsupported_country_region_territory`; они остаются видны в окне tunnel-client.

## Выполненные проверки

- EXE скомпилирован на текущем Windows-устройстве.
- Запуск `Start-MCP-Tunnel.exe --check` завершился успешно.
- Шифрование и расшифровка DPAPI проверены на синтетическом значении.
- Реальный ключ и полный интерактивный запуск пользователь должен проверить при первом открытии EXE; при разработке ключ не запрашивался.
