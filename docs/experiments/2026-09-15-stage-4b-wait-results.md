## Три последовательных вызова — passed

Через авторизованный Chrome в существующий тестовый чат отправлено одно
поручение: три последовательных wait_probe по 60 секунд; при первой ошибке
остановиться. После отправки новых сообщений не было. Итоговый ответ прочитан
через браузер; полные низкоуровневые ответы инструментов отдельно не извлекались.

Общий интервал между первым startedAt и последним completedAt — 185,602 с.
Следующий вызов начинается после предыдущего completedAt. UI указывает
обработку 3m 10s. Промежуточный индикатор оставался на A1 и не отражал
продвижение: по нему нельзя заключать, что первый вызов завис.

Подтверждено продолжение ожидающего хода ChatGPT несколькими короткими вызовами.
Ожидание реального Report, неограниченный цикл и пробуждение завершённого чата
не проверены. Диспетчер Codex для таймеров не запускался; текущий агент Codex
использовался для организации опыта и чтения результата.

## Диагностика туннеля

Readiness во время теста — ready. В локальном каталоге лаунчера нет сохранённых
строк wait_probe. Через документированный /api/logs/export получен диагностический
архив: в нём есть записи "command response deadline reached; dropping without
posting a response" и сетевые таймауты poll. Прямая корреляция с маркерами
wait_probe не установлена; эти записи не считаются доказанной причиной ошибки
180-секундного теста. Архив оставлен в локальном временном каталоге, в Git не добавлен.
